# Özel Denizli Lider Çocuklar Anaokulu

Cute Next.js website for the kindergarten in Merkezefendi / Denizli.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Deploy target: Vercel

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
