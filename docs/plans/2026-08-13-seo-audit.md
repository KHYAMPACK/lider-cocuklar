## HIGH

### SEO-H1 — Inner pages inherit the homepage Open Graph card

`src/app/layout.tsx` sets `openGraph.title` = `site.name`, `url` = `site.url`, `description` = `site.description`, `twitter` similarly.

Child pages set `title` + `description` + `canonical` but **do not** set `openGraph` / `twitter`. Shares of `/hakkimizda`, `/iletisim`, etc. can show the home card and home URL.

Add per-page `openGraph` (title, description, url) and twitter title/description. Keep `metadataBase` so relative URLs resolve.

### SEO-H2 — Homepage `<title>` is well over 60 characters

Layout default: `` `${site.name} | Denizli Merkezefendi Anaokulu` ``  
= “Özel Denizli Lider Çocuklar Anaokulu | Denizli Merkezefendi Anaokulu” (~67+ chars). SERP will truncate.

Shorter unique home title, e.g. “Lider Çocuklar Anaokulu | Denizli Yenişehir” (still Title Case / keyword-honest). Template `%s | ${site.shortName}` is fine for inner pages if the page title part is short.

## MEDIUM

### SEO-M1 — OG image is a square logo, card is `summary_large_image`

`openGraph.images` / `twitter.images`: `/logo.png` (now 512×512). Large cards expect ~1200×630. Either:

- add a 1200×630 share image (grape + logo + short name), or
- switch twitter to `summary` until a wide image exists.

Do not stretch the logo into a fake 1200×630 if it looks broken.

### SEO-M2 — JSON-LD `geo` has no coordinates

`src/components/JsonLd.tsx` `GeoCoordinates` only has `addressCountry`. Empty geo is worse than omitting it. Remove `geo` until real lat/lng are known, **or** add coordinates from the school’s Google Maps pin (do not invent).

### SEO-L2 — Root layout `canonical: "/"` 

Child pages override. `not-found` may inherit home canonical; 404 status should prevent indexing. Optional `robots: { index: false }` on not-found.
